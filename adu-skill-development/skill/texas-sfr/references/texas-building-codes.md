# Texas Building Codes — State Adoption Baseline

Texas sets the minimum building code floor for all municipalities. Cities may locally amend adopted codes upward (more stringent) but generally may not adopt standards below the state baseline.

**Last Verified:** March 2026

---

## Building Code Adoption Framework

Texas does not have a single statewide building code enforcement authority. Instead, the state sets the **minimum adopted edition** for each code type, and local jurisdictions enforce and may amend within that floor.

| Code | State Authority | Texas Baseline | Notes |
|------|----------------|----------------|-------|
| International Residential Code (IRC) | Tex. Gov't Code Ch. 214 | IRC 2021 (effective Sept 1, 2024) | Applies to 1- and 2-family dwellings and townhomes ≤3 stories |
| International Building Code (IBC) | Tex. Gov't Code Ch. 214 | IBC 2021 | Applies to commercial and multifamily ≥3 units |
| International Energy Conservation Code (IECC) | Tex. Gov't Code Ch. 388 | IECC 2021 | Enforced as Texas Energy Code |
| Texas Accessibility Standards (TAS) | Tex. Gov't Code Ch. 469 | 2012 TAS (based on 2010 ADA Standards) | Applies to all new construction and substantial renovation — state equivalent of federal ADA |
| National Electrical Code (NEC) | Tex. Util. Code §§186.001–186.003 | NEC 2020 | Administered by Texas Department of Licensing and Regulation (TDLR) |
| International Plumbing Code (IPC) | Tex. Health & Safety Code | IPC 2021 | Enforced locally; some cities use UPC |
| International Mechanical Code (IMC) | Tex. Gov't Code Ch. 214 | IMC 2021 | |

## International Residential Code (IRC)

**Citation:** Tex. Gov't Code §214.212
**Applies to:** Detached one- and two-family dwellings, townhomes (≤3 stories above grade)
**Current Texas baseline:** IRC 2021

### Key IRC Provisions for SFR Plan Review

| Topic | IRC 2021 Standard |
|-------|------------------|
| Habitable room ceiling height | Min. 7 ft (R305.1) |
| Bedroom egress window | Min. net clear opening 5.7 sq ft; min. height 24 in.; min. width 20 in.; max. sill height 44 in. from floor (R310.2) |
| Stair riser height | Max. 7-3/4 in. (R311.7.5.1) |
| Stair tread depth | Min. 10 in. (R311.7.5.2) |
| Stair width | Min. 36 in. clear (R311.7.1) |
| Guard (railing) height | Min. 36 in. at walking surface ≤30 in. above grade; min. 42 in. above 30 in. (R312.1) |
| Smoke alarms | Required in each sleeping room, outside sleeping areas, each level (R314) |
| Carbon monoxide alarms | Required where fuel-fired appliances or attached garage present (R315) |
| Foundation | Engineered or prescriptive per soil conditions (R401–R403) |
| Wall framing | Prescriptive lumber sizing or engineered design (R602) |
| Roof framing / ventilation | 1:150 ratio (or 1:300 with vapor barrier); ridge/eave balanced (R806) |

### City Amendment Authority
Cities may locally adopt more stringent IRC provisions (e.g., higher ceiling heights, more restrictive egress). They may NOT adopt provisions less stringent than the state baseline IRC edition.

## Texas Energy Code (IECC)

**Citation:** Tex. Gov't Code Ch. 388
**Enforcing authority:** Texas State Energy Conservation Office (SECO)
**Current baseline:** IECC 2021 (effective January 1, 2023 for residential)

### Key Energy Standards for SFR

| Topic | Texas Energy Code (IECC 2021) |
|-------|-------------------------------|
| Climate zones in Texas | Zone 2 (far south TX), Zone 3 (most of Central/South TX, Austin), Zone 4 (North TX) |
| Austin climate zone | **Zone 2** |
| Insulation — walls | R-13 + R-5 (Zone 2/3) |
| Insulation — attic | R-38 (Zone 2), R-49 (Zone 3) |
| Windows — U-factor | ≤0.40 (Zone 2/3) |
| Windows — SHGC | ≤0.25 (Zone 2/3) |
| Air sealing | Required — blower door test or visual inspection |
| Duct leakage | ≤4 CFM25 per 100 sq ft of conditioned floor area |
| Mechanical ventilation | Required per ASHRAE 62.2 |
| Compliance path | Prescriptive (Res Check) or performance (Energy Model) |

### Plan Review Note
A Texas Energy Code compliance report (COMcheck for commercial, REScheck for residential) is typically required at permit submittal. Verify that the plan set references the applicable climate zone and code year.

## Texas Accessibility Standards (TAS)

**Citation:** Tex. Gov't Code Ch. 469
**Enforcing authority:** Texas Department of Licensing and Regulation (TDLR)
**Standard:** 2012 TAS (modeled on 2010 ADA Standards for Accessible Design)

### When TAS Applies
- **New construction:** All new commercial construction and new multifamily residential (3+ units)
- **Alterations:** When substantial renovation occurs (threshold: cost of alteration affects accessibility)
- **Single-family and two-unit residential:** Generally exempt from TAS; accessible design is voluntary unless publicly funded

### Key TAS Requirements for Multifamily (if applicable)
| Topic | TAS Standard |
|-------|--------------|
| Accessible parking ratio | 1 accessible space per 25 total (§208) |
| Accessible route | Continuous, connecting parking to entrance (§402) |
| Accessible entrance | At least 60% of entrances must be accessible (§206.4) |
| Door clear width | Min. 32 in. clear at 90° (§404.2.3) |
| Ramp slope | Max. 1:12 (§405.2) |

### Plan Review Note
For standard SFR and two-unit residential, TAS is generally not in scope. Flag TAS for any three-unit or multifamily project and any commercial conversion.

## National Electrical Code (NEC)

**Citation:** Tex. Util. Code §§186.001–186.003
**Enforcing authority:** Texas Department of Licensing and Regulation (TDLR) for electricians; local authority having jurisdiction (AHJ) for inspections
**Current baseline:** NEC 2020

### Key NEC 2020 Provisions for SFR
- AFCI protection required in all 120V, 15/20A branch circuits (§210.12)
- GFCI protection required in all bathrooms, kitchens, garages, exterior, unfinished basements, crawl spaces (§210.8)
- Tamper-resistant receptacles required in all accessible locations (§406.12)
- Arc-fault circuit interrupter (AFCI) required for bedroom circuits

## City Amendment Authority — Summary

| Code | City Can Adopt More Stringent? | City Can Adopt Less Stringent? |
|------|-------------------------------|-------------------------------|
| IRC | Yes | No |
| IBC | Yes | No |
| Texas Energy Code | Yes | No |
| TAS | Yes | No |
| NEC | Yes | No |

**Plan review implication:** If a city's locally adopted code edition is newer than the state baseline, use the city's edition. If a plan references a code edition older than the state baseline, flag it — the state minimum governs.
